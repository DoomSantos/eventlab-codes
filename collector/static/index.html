DSR Lap Collector Lab

Sign in once, turn on Data Out, then drive. Clean Time Attack laps upload by themselves.

Lab mode: path captures, labels, local DB, and detect diagnostics. Drivers use the normal UI (drop ?lab=1).

Setup
  1. Sign in — paste your invite and a display name, then Claim invite (once per PC).
  2. In FH6: Settings → HUD and Gameplay → Data Out → On. IP 127.0.0.1 · Port 9876 (do not use 5200–5300).
  3. Load a DoomSantos Time Attack event and start from the pit / offset grid. Leave this collector running.
  4. When status says Game connected, finish clean laps. They upload on their own — you don’t pick a track or press send.

Troubleshooting

Windows blocked the program

If Windows says it protected your PC: choose More info, then Run anyway. That is normal for this small app.

Keep the collector window open while you race. The browser page is just the display — closing the app stops uploads.

Stuck on “Waiting for game”

Data Out only sends while you are driving — not in menus, pause, replay, or rewind. Pull away and watch for Game connected.

Check IP and port digit-for-digit. Same PC → 127.0.0.1. Do not use ports 5200–5300 (FH6 uses those itself).

Run only one collector. Close SimHub or other telemetry apps — FH6 can send Data Out to one place at a time.

Restart FH6 after turning Data Out on. If a Microsoft Store / Xbox copy of the game still never connects, message DSR for the one-time Windows fix.

Windows Firewall may be blocking UDP 9876 — allow it, then restart this collector.

Game connected, but no laps

You must cross the line to finish a full lap. Use a Time Attack share code — other EventLabs do not count for the public board.

Start from the event’s pit / offset grid so the status shows Time Attack. Later laps keep that mode automatically.

Lap says Rewound or didn’t upload

Rewind (or a big mid-lap jump) marks the lap Rewound — it stays off the public board. Drive the next lap without rewinding.

Status Clean + Time Attack and Uploaded Sent means it reached the board.

Signed in, but nothing reaches the board

You should see “Signed in as …”.

You need internet for uploads. Clean laps queue here and retry when the board is back.

A new PC (or a reset collector) needs a replacement invite from DSR for the same display name, so your old times stay attached. Don’t pick a new name.

It was working, then it stopped

Alt-tab, sleep, or leaving FH6 can pause Data Out. Start driving again and confirm Data Out is still On. Restart the game if the status stays on Waiting for game.
